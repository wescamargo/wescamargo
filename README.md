## 🛠 O que eu construo · What I build

| | 🇧🇷 | 🇺🇸 |
|---|---|---|
| 🏛 | **Plataforma de dados** Bronze → Silver → Gold, com cada tabela e cada carga versionadas em Terraform | **Data platform** Bronze → Silver → Gold, every table and every load versioned in Terraform |
| ⚡ | **Ingestão** em tempo real (CDC) de bancos transacionais, APIs e scrapers | **Real-time ingestion** (CDC) from transactional databases, APIs and scrapers |
| 👁 | **Observabilidade**: agentes que vigiam atraso, volume e falha de job e avisam antes de alguém perceber | **Observability**: agents that watch freshness, volume and job health, and alert before anyone notices |
| 🤖 | **IA aplicada a dados**: skills e agentes com Claude que consultam, criam tabelas e abrem PR no padrão do time | **AI for data**: Claude skills and agents that query, create tables and open PRs following team standards |
| 🔐 | **Governança e custo**: acesso por grupo, dicionário de dados vivo e custo acompanhado de perto | **Governance and cost**: group-based access, a living data dictionary and close cost tracking |
